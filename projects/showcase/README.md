# Showcase Programs

This folder contains small IRIS programs that exercise the language's current strengths:

- `mathlab.iris` - recursion, loops, matrix math, and sieve-style computation.
- `textlab.iris` - string processing, tokenization, and summary reporting.
- `records.iris` - records, aggregates, and branch-heavy reporting.

Run them from the repository root with:

```bash
iris run projects/showcase/mathlab.iris
iris run projects/showcase/textlab.iris
iris run projects/showcase/records.iris
```
